Разработка этого бота в 4х сериях на Ютубе https://www.youtube.com/playlist?list=PLT7fv9a9OkgZX8jE01AKygRVAbjiZ-JX7

---
Локально можно запустить с ngrok.

конфигурация:
```bash
ngrok config add-authtoken ***
ngrok http 8080
```
отключить ssl:
```
server.ssl.enabled=false
```

Подробная инструкция: https://www.youtube.com/embed/scS025PkuG8
